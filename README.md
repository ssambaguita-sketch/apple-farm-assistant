# 최종 사과 재배 관리 비서 2.0

지금까지 만든 기능을 하나의 실행 구조로 통합한 최종 베이스 버전입니다.

## 통합 기능
- 과수원 등록: 품종, 면적, 나무 수, 생육단계, GPS
- GPS → 기상청 격자 자동 변환
- 기상청 단기예보 API 연동
- 강수·풍속·습도·고온 기반 작업 적합시간 TOP 5
- 작업 등록/완료/우선순위
- 작업 60분 전 Telegram 알림
- 병해충 관찰 및 위험점수
- 잡초 유형/생육단계/밀도 기록
- 제초 후 살아남는 잡초 원인 분석
- 동일 작용기작 반복 여부 점검
- PSIS 등록약제/작용기작/안전사용기준 확인 안내
- 비용·매출·수확량·순이익 DB
- 작업효율 개인화 코치
- 개인화 코치는 생체정보를 추론하지 않고 작업완료·시간대·체감난이도만 사용

## 서버 환경변수
KMA_SERVICE_KEY
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
APPLE_FARM_DB

## 백엔드 실행
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## Flutter
```bash
flutter pub get
flutter run
```

Android 에뮬레이터 기본 API 주소는 http://10.0.2.2:8000 입니다.
실제 휴대폰에서는 FarmApi의 baseUrl을 서버의 LAN/HTTPS 주소로 변경하십시오.

## 농약/제초제 안전
앱은 특정 농약의 임의 증량, 등록 외 사용, 임의 혼용을 처방하지 않습니다.
실제 사용 전 농촌진흥청 농약안전정보시스템(PSIS)과 제품 라벨에서
작물명, 적용 병해충/잡초, 사용방법, 희석배수/사용량, 사용시기,
사용횟수, 작용기작, 안전사용기준을 확인하십시오.
